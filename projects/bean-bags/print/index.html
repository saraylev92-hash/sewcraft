Print pattern · Juggling Bean Bags (set of 4)

  1. STEP 1

    Print the test page

    In the print dialog choose Actual size / 100% — never “Fit to page”.

  2. STEP 2

    Measure the squares

    The squares must measure exactly 5 cm and 2″. If not, check printer scaling and print again.

  3. STEP 3

    Print the pieces

    2 pages. Trim along the solid border where pages meet, then match the ◆ marks and tape.
