  1. STEP 1

    Print the test page

    In the print dialog choose Actual size / 100% — never “Fit to page”.

  2. STEP 2

    Measure the squares

    The squares must measure exactly 5 cm and 2″. If not, check printer scaling and print again.

  3. STEP 3

    Print the pieces

    19 pages. Trim along the solid border where pages meet, then match the ◆ marks and tape.

Fabric

  • Drapey woven fabric: 1.7 m of 150 cm wide (single)

Sample pattern — not yet test-sewn. Pattern rules: Geometry, not scaling: waist radius r = (hip + 4 cm) ÷ 2π, so the waist edge is long enough to pull over your hips; the outer radius is r + length − band + hem. Each quarter is cut with 1.5 cm side seam allowances. The cutting layout packs each quarter's bounding square — nesting the quarters can save fabric on wide bolts.
