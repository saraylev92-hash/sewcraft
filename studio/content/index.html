Content review

Every file in content/projects/*.json is loaded and checked against the content rules (tools & materials defined, valid geometry at every size extreme, explicit seam allowances, piece references consistent across materials → cutting → steps, diagrams generated from the pattern data, logical stage order, a visual for every step, and editorial review). Only published projects with no errors appear in the app. Run npm run validate to check in CI.
