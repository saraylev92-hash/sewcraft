Elastic waistband

Cut, thread and join elastic for a comfortable fit.

Elastic is cut shorter than the body measurement so it grips gently — about 90% of the waist plus a 2 cm overlap. Thread it with a safety pin, check it isn't twisted, overlap the ends and zigzag in a box.

Video demonstration: not yet available.

How to do it

  1. 1Cut elastic to 0.9 × waist + 2 cm.
  2. 2Pin one end to the casing so it can't disappear.
  3. 3Feed it through with a safety pin.
  4. 4Overlap ends 2 cm, zigzag a box, close the casing.

You'll need

  • Safety pin
  • Zigzag stitch

Common mistakes

  • Twisted elastic.
  • Using non-woven 'braided' elastic that narrows when stretched.
